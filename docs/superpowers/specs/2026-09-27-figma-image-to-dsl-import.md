# Figma 式设计图转 UI-DSL

## 用户目标

设计人员可以把页面截图当作 Figma 设计输入，自动得到可编辑的页面结构。截图识别结果通过 UI-DSL 的同一套 schema、预览 renderer、撤销历史、保存和发布门禁。

## 工作流

1. 在 Studio 设计页点击“图片转 UI-DSL”，选择 PNG、JPEG 或 WebP，也可将图片拖入上传区；也可以在画布 AI 对话框用“＋”附加参考截图并填写还原要求，直接进入同一转换流程。
2. 选择自动识别、企业官网或管理平台；可输入还原重点。
3. 浏览器先限制像素和源文件大小，再将整图缩小至最长边 1800 px；如果原图更大，同时切出最多两块原始分辨率细节图，记录各自对应的整图坐标。每块细节图最多 4 MB，两块合计最多 8 MB。
4. 服务端验证整图与细节图边界，将整图缩小到最长边 1800 px 并编码成 JPEG；单次视觉模型请求同时接收整图和细节图。模型输出页面类型、最多 120 个区域的边界框、语义图层名、逐字识别的可见文案、可选样式和容器布局；流式子图层还可声明固定、Hug 或 Fill 尺寸，只有从画面能明确判断的模式才返回。单个文案图层最多 2000 字，较长文案按阅读顺序拆分，不截断原文。细节图只辅助读取文案/控件，区域坐标仍使用整图坐标。文案字段与图层名分开，避免将摘要误作页面文字；无法辨认的文案保存为空白、可编辑的 Text/Button 图层，并在识别说明中提示。容器可声明有界的 flow/absolute 模式、行列方向、间距、内边距、对齐和分布；只有规则行列且无重叠的子图层使用 flow，浮层、图表和自由布局继续使用 absolute。编译阶段会再次检查 flow 容器的直接子图层；如边界框仍有交集，自动将这些子图层降级为 absolute 并在识别说明中告知用户。Hug / Fill 只应用于最终保留为 flow 的子图层，其余区域继续使用截图测量尺寸。重复出现的填充色和文字色自动归并为以 `Color / #RRGGBB` 命名的页面颜色变量，并绑定到对应图层；最多创建 64 个变量，超出部分保留固定颜色。达到 120 个区域上限时，预览说明会提示用户分块导入，避免把可能遗漏的图层误认为完整结果。`parentIndex` 指向先前声明的 Frame/Card 容器，用于恢复父子关系。服务端代码再把区域计划确定性地编译成 UI-DSL，避免让模型再次生成时改写坐标。
5. 服务端校验图片 MIME、解码结果、像素尺寸、请求权限、区域计划和完整 UI-DSL；模型只能输出白名单组件和有界设计属性。根 Frame 位于 `pageDsl.nodes[0]`，尺寸按参考图宽高比校准；Frame 默认裁切超出画框的子内容，子图层使用父级局部坐标，超出父容器的部分裁切到容器范围。画板缩放时，同步缩放节点坐标、固定宽高、字体尺寸、字距、描边、圆角，以及 Frame 的间距和内边距，保持画布比例与自动布局密度一致；最后重新验证完整 DSL。最终页面最多接收 150 个节点（含根画板）；正常区域数上限为 120。
6. Studio 用共享页面 renderer 预览候选 DSL，显示识别说明；图片区在浏览器内临时裁切并以对象 URL 预览，不上传、不写入页面素材。未经用户点击“应用到画布”不得修改现有草稿或保存图片素材。
7. 应用时走设计 store 的 `replaceDraft`，作为单个可撤销修改进入同一规范 DSL；图层、检查器、导出和发布随后直接读该 DSL。
8. 如果模型识别出图片区域，应用按钮会先调用受保护的素材接口：服务端按有界坐标从压缩参考图裁切 PNG，限制最多 24 块、合计不超过 5000 万裁切像素和 20 MB，再绑定到目标页面。画布应用前所有裁片必须保存成功；原始整张截图只留在弹窗内存，不作为页面素材保留。

## Figma 式编辑工作区

- 左侧 Pages 区域列出当前设计页；组件/图层面板切换资源和结构。
- 中间是自由画布与页面画板。画布对象可选中、移动、缩放，视口移动和缩放不进入页面 DSL。点击图层选择对象，Shift/Ctrl/⌘ 点击切换该对象的选中状态；从画布空白处拖动可框选对象，按住修饰键拖框会把结果并入当前选区；被隐藏或锁定的图层不参与框选。
- 右侧属性检查器按页面、组件和基础图层类型显示有界编辑字段。
- 图层树可折叠子树并切换可见/锁定状态；隐藏状态影响画布与发布输出，锁定状态阻止直接移动/缩放但不阻止从图层树选择。
- 底部浮动工具提供选择、Frame、Shape、Text、Image；选择绘制工具后点击画布按默认尺寸放置，拖拽时按指针范围创建对象。一次放置提交一条 UI-DSL/history 操作；Esc 或选择工具退出绘制模式。
- 底部工具同时操作撤销/重做、设备尺寸和缩放。
- 画布编辑、AI 对话和截图转入的页面共用同一份 UI-DSL，不维护一个隐式 Figma JSON 副本。
- 画布 AI 对话显示修改目标；有选区时只接受所选节点及其子树的变更，页面其余内容和数据字段保持不变。无选区时允许整页修改；锁定选区必须先解锁。
- Prototype 检查器可配置按钮、网站导航、Hero 行动按钮和行动区块跳转；所有目标都引用现有 ContentSection.sectionId，并由 DSL 校验、预览 renderer 和页面生成器共用。

## 模型与图片约束

- 视觉模型通过 OpenAI 兼容 Chat Completions 接收 `image_url`；可使用 `PULSEFLOW_VISION_API_URL`、`PULSEFLOW_VISION_MODEL_NAME`、`PULSEFLOW_VISION_API_KEY`、`PULSEFLOW_VISION_TIMEOUT_MS` 独立配置。
- 视觉调用要求 JSON 输出；Qwen 视觉模型关闭思考模式。最多识别 120 个区域，并保留可解析的容器层级；最终 UI-DSL 限制为 150 个节点，供用户继续在画布中细化。
- 未设置专用变量时回退到通用模型配置；该模型必须支持图片输入。
- 输入只接收 PNG/JPEG/WebP，源文件最大 20 MB、解码像素最多 5000 万；整图最多 5 MB，每块细节图最多 4 MB、合计最多 8 MB，请求总大小限制为 18 MB。
- 图片不保存为页面资源，不写数据库或日志。界面明确告知图片会发送到当前模型服务。
- 用户指令与截图内文字一律作为不可信数据。服务端拒绝任意 HTML、CSS、脚本、未注册资源 ID、未知 DSL 属性和无效字段引用。
- 模型超时、拒绝、JSON 错误或 schema 错误时保留原页面；不能因截图识别绕过发布门禁。

## 验收要求

- PNG、JPEG、WebP 可经上传或拖放进入转换流程；无效格式、空图、过大文件和超像素图会给出明确错误。
- 视觉分析请求包含图像与用户约束；区域计划经 schema 校验后由服务端确定性编译，不再进行第二次文本生成。返回页面通过完整 DSL 校验和 150 节点上限。
- 转换后根 Frame 的宽高比例与处理后参考图一致；绝对定位子图层坐标和尺寸按目标画板同步缩放，自动布局容器的子图层使用 flow 模式并保留识别出的方向、间距、内边距和对齐属性，所有空间样式量按相同比例缩放。
- 自动布局子图层只有在模型明确返回尺寸模式时才保存 Hug / Fill；实时预览和发布按相同 Figma 尺寸规则渲染，其余子图层使用识别得到的固定尺寸。
- 原图长边超过 1800 px 时，转换请求同时携带整图和覆盖完整截图的高清细节图；细节图只影响识别内容，DSL 节点仍使用整图坐标。
- 转换结果在提交前可预览；拒绝、关闭或请求失败时原画布不变。
- 候选预览里的图片区使用浏览器内生成的裁片对象 URL；切换截图、重新生成或关闭面板时释放所有临时 URL。
- Apply 后识别到的图片区域使用实际截图裁片而非纯色占位，并通过页面素材端点随页面预览和发布；取消导入时不保存裁片。
- 接受结果后，画布标题、图层树、预览和源码都反映同一 DSL；撤销/重做可恢复变更。
- API 要求工作区身份验证，并对图片转换端点限速；外部错误不回显密钥或上游响应正文。
