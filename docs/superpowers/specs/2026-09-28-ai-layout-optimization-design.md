# 导出前 AI 布局优化设计

## 目标

导出 Vue 项目时，用户可以选择 AI 分析页面截图和 UI-DSL，将视觉上构成规则行列的绝对定位图层转换为真实 Flex 布局，并在下载前检查转换结果。

## 现状

- `StudioFileExportPanel` 在浏览器内生成包含全部页面的 Vue ZIP。
- UI-DSL 使用 `design.position.mode` 区分 `absolute` 和 `flow`；`Frame` 的 `direction`、`gap`、`padding`、对齐属性由页面生成器输出为 Flex。
- Studio 已有 `autoLayoutNodesCommand`。它要求选择同级、连续、未锁定、未旋转的图层，并检查共线、无重叠、等间距；通过后会将它们组合为流式 Frame。
- 视觉导入已有多模态模型请求、图片压缩和输出约束，但没有页面 DOM 截图能力。

## 设计

### 导出流程

在“导出 Studio 项目”中显示含绝对定位节点的页面列表。AI 布局优化为可选项，按用户勾选的页面逐页分析。未选择 AI 时保持现有直接导出行为。

对勾选页面，在隔离的预览节点中用 Studio 的 `PreviewPanel` 按目标画板尺寸渲染真实页面，并生成受大小限制的 PNG 截图。截图和 UI-DSL 一起发送到受工作区 Token 保护的布局分析接口。只发送被选中的页面；页面文案、图像和截图都按不可信输入处理。服务端按 `layoutOptimization` 用途读取共享 Skill 目录中的启用规则；该目录也供项目开发助手自动发现。

模型只返回 `{ groups: [{ nodeIds: string[] }] }`，不得返回 DSL、代码、CSS 或自由格式修改。客户端检查每组 ID 唯一、存在且互不重叠，然后复用 `autoLayoutNodesCommand` 及实际预览 DOM 的几何数据生成候选 DSL。命令自身负责同父级、连续顺序、锁定、旋转、对齐、重叠、间距和 UI-DSL 校验；不合格的组保持原样并显示原因。绝对定位的图表、浮层、重叠装饰不会被强制转换。

优化只作用于导出文件副本，不写回当前页面、撤销栈或 Studio 存档。候选页面重新渲染并生成预览，用户可逐页选择原版或候选版；最终 ZIP 仍经过既有 DSL 校验和图片素材校验。

### 模型与接口

- 新增布局分析 API，复用视觉模型配置和现有图片输入校验逻辑。
- 请求包含一张受限尺寸的 PNG、一个有效页面 DSL 及当前工作区启用的 `layoutOptimization` Skills。
- 路由限制请求字节、节点数、图片像素、超时和模型返回大小；模型只可引用输入页面已有节点 ID。
- 服务端校验 DSL 与图片后调用视觉模型，严格解析 `groups` schema，并校验 ID 唯一性；客户端再用自动布局命令验证空间几何。
- 模型失败或没有安全候选时显示可读原因，允许用户导出原版。

### 视觉预览

增加独立的页面截图/预览子组件，使用固定宽度的 `PreviewPanel` 实例渲染单页；截图前等待 Vue 更新、图片解码和字体就绪。截图实现选用浏览器端 DOM 转图片依赖，限制宽度 1440 像素、PNG 请求数据不超过 API 请求上限。候选截图用于并排比较，不用截图像素差代替 UI-DSL 校验。

## 安全与数据完整性

- 不执行模型返回代码；接口只接受节点 ID 分组。
- API 对认证、请求大小、图片格式、DSL schema、节点数量和模型响应长度做验证。
- 原文件对象保持不可变；候选导出文件通过拷贝应用变更。
- 模型不会修改文字、业务 props、颜色变量、事件、数据字段或图片引用。
- 只从服务端配置的 Skill 目录读取格式有效的 Markdown Skill，不接受请求体覆盖 Skill 正文。
- 每个候选转换都须经过 `validatePageDsl` 和现有 `autoLayoutNodesCommand`；失败只丢弃该候选组。

## 验收标准

1. 导出 UI 列出含绝对定位图层的页面；用户不勾选 AI 时原导出行为不变。
2. 勾选页面后，模型同时接收真实 Studio 预览截图和有效 UI-DSL。
3. 模型只能返回页面已有节点的分组；未知 ID、重复 ID、重叠组和结构错误不能改变候选 DSL。
4. 只有通过既有自动布局检查的组才会生成 Flex Frame；布局不规则或有重叠的图层保持绝对定位。
5. 用户可比较原版和优化预览，并逐页选择导出版本。
6. AI 优化不改编辑器当前 DSL、保存项目、历史记录和已发布版本。
7. 模型超时或失败时仍可下载未优化的 Vue ZIP，并看到可理解的状态。

## 范围

本功能针对 Studio 项目 ZIP 导出，不修改发布流程和 UI-DSL schema；不让模型生成或执行任意前端代码。
