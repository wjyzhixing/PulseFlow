# PulseFlow Studio Ant Design 风格视觉改版

**状态：** 方向已由用户选择（B：Ant Design 控制台风格）  
**日期：** 2026-09-26

## 目标

将 PulseFlow Studio 从当前带有深色叙事侧栏、荧光绿、大号衬线标题、点阵背景和厚重阴影的视觉，调整为接近 Ant Design 企业工作台的克制、清晰和高信息密度界面。用户希望其观感贴近 Ant Design 官网的设计语言。

本次只改 UI。登录、需求导入、模型生成、字段和 DSL 编辑、画布操作、预览、发布、路由及 API 行为保持不变。

## 设计方向

- 使用 Ant Design 常见的中性色工作区、白色内容面、蓝色主操作和细边框层级。
- 字体使用中文系统 UI 字体栈；页面标题采用产品工作台常见的中小字号与中等字重，避免杂志式衬线排版。
- 使用统一的颜色、间距、圆角、边框、焦点态、禁用态及状态色，减少组件各自为政。
- 使用轻量分隔线和克制阴影；移除装饰性点阵、渐变、超大标题及强烈投影。
- 按 Ant Design 控制台而非文档站信息架构处理。保留已有四步流程导航、页面内容次序和设计器三栏工作区，以标准导航、标题、表单、面板和状态样式重绘。
- 保留现有 Vue 组件和事件/API 接口，不增加 UI 依赖，不把纯视觉工作扩展为新的交互或功能。

## 覆盖范围

Studio 登录页、需求导入与章节选择、草稿确认、空白画布入口、设计画布、组件面板、字段与属性编辑器、DSL 编辑器、预览区及发布检查面板。

整体工作台采用浅灰背景和白色顶栏/内容面，流程导航以紧凑、可辨识的当前步骤状态呈现。表单控件、按钮、卡片、标签、提示、错误信息、校验状态和发布状态共享同一套视觉规则。设计画布仍突出页面预览，组件、实体字段、属性及 DSL 编辑区域以轻分隔和一致的面板层级呈现。

## 约束

- 不改 API 请求、数据结构、校验逻辑、模型提示词、生成逻辑、发布门槛或 CLI。
- 不删除或新增现有操作，不改变按钮行为、路由和流程状态。
- 保留既有测试定位属性和可访问性语义。
- 保持窄屏可用；不因重排布局隐藏现有功能。
- 实现优先复用现有 ant-design-vue 依赖及 CSS 变量，不做全量组件替换，以降低视觉重构对行为的影响。

## 验收依据

1. Studio 所有阶段共享一致的浅色中性表面、Ant Design 蓝主操作、常规系统字体和轻量分隔层级。
2. 原有深色叙事侧栏、荧光色装饰、点阵背景、衬线大标题和厚重卡片阴影不再主导视觉。
3. 登录、导入、确认草稿、编辑画布、预览和发布的所有现有控件仍可见、可操作，流程及结果与改版前一致。
4. 画布在桌面端保持编辑器所需的多栏工作区，在窄屏下仍能访问所有面板。
5. Vue 类型检查和 Studio 构建通过；浏览器检查桌面及窄屏主要页面，确认布局与样式落地且没有明显溢出。
