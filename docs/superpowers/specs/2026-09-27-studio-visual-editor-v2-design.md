# PulseFlow Studio 2.0 可视化编辑器设计

**状态：** 实施中（范围由用户授权）  
**日期：** 2026-09-27

## 目标

把 Studio 做成参考图所示的 Figma 式设计工作台：设计人员从 Pages/Layers 组织对象，在大型画布上直接选择、移动、缩放页面元素，并在右侧用 Position、Layout、Appearance、Typography、Fill 检查器精调。每次视觉操作都自动转换成可验证、可预览、可导出的 UI-DSL；设计人员不需要手写代码。

本规格已按用户提供的 Figma 工作区截图修订。原先仅能操作语义组件树、禁止节点坐标的限制不再适用于设计对象。新版 DSL 允许受边界约束的几何属性，但不接受任意 CSS、脚本或不可导出的绘图状态。

## 用户与任务

主要用户是了解页面层级、视觉样式和内容的 UI/网页设计人员，不要求其编写 JSON、Vue 或 CSS。技术人员仍可查看、复制和下载 DSL；源码编辑属于高级能力，不是默认入口。

设计人员可以：

1. 在真实页面画布上看到接近发布效果的页面，而不是节点卡片清单。
2. 点击画布上的 UI 元素直接选中；图层面板与画布选择双向同步。
3. 从组件库添加页面区块和控件；拖放到合法的插入位置或容器中，并在画布及图层树中排序。
4. 在右侧检查器使用中文标签编辑已选对象的内容、样式和绑定。字段只显示该组件适用的设计选项。
5. 在桌面、平板和手机画布宽度间切换，缩放和适配画布视口。
6. 撤销/重做设计操作，查看即时校验状态。
7. 通过导出面板复制或下载校验通过的 DSL；无效编辑显示路径和修复建议，不能作为有效导出或发布。
8. 将 Frame、Text、Shape 和 Image 当作独立设计图层新增、嵌套、移动、缩放、旋转、复制和删除；常见控件也可以保留成语义组件。
9. 在右侧检查器修改 X/Y、宽高和 Hug/Fill 模式、对齐、旋转与水平/垂直翻转、透明度、圆角、文字字体/字号/字重/行高/字距/对齐、填充与描边。
10. 以同一份 DSL 同时保留自由设计对象与语义组件；设计对象生成稳定 Vue/HTML/CSS，语义组件继续使用页面生成器组件注册表。

## 核心模型与约束

- UI-DSL 是唯一持久化事实来源。画布、图层、检查器、预览、AI 对话修订、保存、发布和导出都从它读取状态。
- 编辑命令先创建不可变候选 DSL，再通过 `validatePageDsl` 及字段校验；通过后一次性提交，失败时保留最后一份有效 DSL 和画布。
- Pages、Layers、画布选择、移动、缩放、旋转、属性检查器和导出都读写同一份经过校验的 UI-DSL。编辑器视口和选择状态仍为临时状态。
- DSL 支持 Frame、Text、Shape、Image 设计图层，也支持现有表格、表单、导航、Hero 等语义组件。Figma 式每项设计动作必须落到一种已命名的 DSL 属性或结构命令。
- 每个节点可在 `design.name` 中保存独立图层名称；图层树双击重命名，右侧检查器提供同一名称字段。该元数据由 DSL 校验与导出保存，不映射成页面可见文本或任意 DOM/CSS。
- 几何数据使用有限范围的父级局部坐标和宽高；布局模式明确区分 flow、absolute、hug、fill。旋转和水平/垂直翻转使用独立的 DSL 字段，由预览 renderer 与页面生成器组合为受限 transform。渲染器负责从这些 token 生成 CSS。DSL 不接受任意 style 字符串、任意 CSS 属性或脚本。
- 页面尺寸、组件尺寸、X/Y、旋转、透明度、圆角、颜色、字体与排版都有 schema 边界；超范围或无效编辑不提交，并显示具体诊断。
- 画布运行与正式预览/代码生成共用 `renderPage` 和组件注册表。编辑态通过节点 ID 映射实现选中、聚焦和编辑覆盖层；选择状态、辅助线和覆盖层不能进入导出 DSL，`design.name` 等可持久化设计属性会保留。
- 结构仍是 DSL 树，但面向用户显示为“图层”，节点名称显示为中文组件名和有意义的内容摘要，而不是原始 JSON。
- 一个命令是一个撤销单元。连续文本输入按短时间窗口合并；拖动、添加、删除、粘贴、AI 接受和批量修改各自保留清晰历史步骤。撤销栈设置上限，选择、缩放和视口变化不进入文档历史。
- 断开/刷新恢复的是已保存草稿；未保存变更在离开时提示。发布仍受现有发布门禁约束，发布版本不可变。

## 工作区布局

1. **顶栏**：页面名/保存状态、撤销/重做、设备预设、缩放与适配、预览、导出、发布。
2. **左侧导航与资源区**：窄图标栏切换 File、Assets、Tools、Variables；旁边显示 Pages 列表和 Layers 树。图层显示类型图标、中文名称、可见/锁定状态，支持选择、重排、折叠和键盘访问。插入对象由底部工具栏完成。资源面板与检查器之间使用可拖动分隔线调整宽度，支持方向键微调（Shift 加方向键以较大步进调整），并在本地记住宽度。
3. **中间画布**：宽阔浅灰工作区，中央显示真实页面 artboard；同一个 Page 可放置多个顶层 Frame，保持各自的画布坐标并一起缩放/平移。页面对象有选择描边、8 点尺寸控制柄和对齐参考线。支持拖动、缩放、平移、框选与多选；滚轮平移画布，Shift+滚轮横向平移，Ctrl/⌘+滚轮以指针位置为锚点缩放；空格拖动和鼠标中键拖动也可平移。在画布空白区域用 Frame/Shape/Text/Image 工具会新增顶层对象，在 Frame 内使用工具会创建子图层。底部浮动工具栏提供选择、Frame、Shape、Text、Image、缩放和适配。
4. **右侧检查器**：参考图分区和控件密度。无选择时显示页面尺寸和主题；选择 Frame/Shape/Image 时展示 Position、Layout、Appearance、Fill；选择 Text 时额外展示 Typography；语义组件继续展示对应业务属性。组件内容字段嵌在同一个检查器面板中，不再和 Figma 检查器重复显示独立的标题/卡片；多选只显示可批量应用的属性，避免只修改首个选中图层。所有表单输入和画布拖动均提交 DSL 候选。
5. **Prototype 连线**：切换 Prototype 后，选中 Frame 会显示连接手柄；从手柄拖至另一个 Frame 可创建连线，画布绘制已有连线。触发方式与目标 ID 存入受校验的 UI-DSL，预览与导出页面执行相同的点击跳转。
6. **底部状态/弹层**：校验数量、画布尺寸和缩放；源码导出是独立高级面板，不挤占默认设计工作流。

## 自动布局

- 多选同一容器中连续、未旋转/翻转、已对齐且无重叠的单行或单列图层，可通过工具栏“自动布局”或 Shift+A 转为 Frame 自动布局。
- 命令从画布实际几何推断方向、元素顺序和等距 gap；保留固定尺寸与视觉边界，并将全部图层写入 `flow` 子节点。
- 不规则、间距不一致、跨容器或缺失几何的选区必须失败并显示原因；失败不得提交部分结构。
- 一次自动布局是单条 UI-DSL 校验和撤销历史记录，并选中新建 Frame。

## 编辑行为

### 颜色变量

- 每页可在 `theme.colorVariables` 中保存最多 64 个颜色变量；变量包含稳定 ID、唯一名称和六位 HEX 值。
- 图层 Fill 和文字颜色可绑定变量 ID。预览和生成页面用页面根节点的 CSS 自定义属性解析变量，更新一个值会同步影响所有绑定图层。
- Typography 提供 PingFang SC、Noto Sans SC、Inter、Roboto、Arial、衬线、等宽和系统默认字体；这些固定字体选项由 UI-DSL 白名单校验，画布、截图识别和生成页面共用同一字体映射。
- 删除仍被引用的变量会被禁用；重复 ID/名称、未解析引用以及同一颜色同时设置固定值和变量引用都会导致 UI-DSL 校验失败。

### 选择与属性

- 在画布点击一个节点，只选择命中元素最深层的 DSL 节点；交互式控件在编辑态不得触发业务事件或导航。
- Escape 逐级取消选择；图层树和画布使用同一 `selectedNodeId`。
- 图层树双击可重命名；空名称清除显式名称并回退到组件内容摘要，重命名作为普通 DSL/history 操作保存。
- 图层树可按名称、ID 或字符串属性搜索；命中子图层时保留祖先路径，命中容器时显示完整子树。
- 选中描边、尺寸标记和插入位置标记仅是编辑器叠层，不参与正式页面渲染和 DSL 序列化。
- 编辑器用白名单属性元数据生成表单控件，并提供中文标签、提示、单位、有效范围和预设；未知属性不通过自由字符串写入。

### 画布变换与布局

- 拖入画布外框：插入根级可用区块。
- 拖到节点之间：插入同层对应位置；拖入容器高亮可接收状态，按组件/slot 白名单新增子节点。
- 非容器、禁止的组件组合、循环嵌套和不支持的 slot 均显示禁止指针/原因，不修改 DSL。
- 设计图层可在父 Frame 坐标系中移动、缩放、旋转；结构变化和几何变化分别产生清晰的 DSL 命令。
- 拖入画布外框插入根级对象；拖到节点之间调整图层顺序；拖入 Frame 内部创建子图层。语义组件仍按容器/slot 能力白名单校验。
- 拖柄修改有限范围的 x/y/width/height，并按 1 CSS px 精度写入 DSL，不隐式吸附到固定间距网格；移动对象时通过边缘和中心线智能对齐，并显示临时参考线。属性面板提供精确数值与 Hug/Fill/Fixed 约束。所有几何属性都能由 renderer 和页面生成器稳定导出。
- Frame 默认裁切超出画框的子内容，并可在 Layout 检查器中关闭；此状态保存在 UI-DSL，实时预览和生成页面使用同一规则。Frame 自动布局的直接子图层把主轴 Fill 编译为弹性剩余空间分配，把交叉轴 Fill 编译为容器拉伸；绝对定位子图层继续按画布坐标定位。实时预览与生成页面使用相同的尺寸语义。

### 设备、视口与画布

- 对普通响应式页面，设备预设只改变 artboard CSS 宽度和预览数据视图，不写入页面节点树。
- 对以固定尺寸 Frame 开头的 Figma 设计稿，根 Frame 的 DSL 宽高就是画板尺寸；编辑画布去掉实时预览卡片外框，并让 stage、shell 和缩放锚点使用该尺寸。切换设备预设不会改写或压缩这个固定画板；需要多尺寸设计时应使用不同 Frame。
- 页面样式通过共享主题 tokens 和 DSL 声明导出；画布缩放不更改实际组件尺寸。
- 桌面/平板/手机的同一份普通页面 DSL 可形成断点预览；只有 schema 明确支持的响应式规则可编辑并导出。

### 历史、持久化、AI 与导出

- 文档命令 API 接收当前有效 DSL，返回 `{ dsl, selection?, description }` 或带诊断的拒绝结果。历史以 DSL 快照或可逆命令保存，序列化时只包含页面设计。
- AI 对话返回修订候选，不直接覆盖画布。设计人员可预览变更并接受/拒绝；接受是单个撤销单元。
- 画布 AI 对话框可附加 PNG、JPEG 或 WebP 参考图；附图和文本要求沿用同一截图转 UI-DSL 识别、预览、校验与应用流程。
- 导出入口默认提供“复制 DSL”和“下载 JSON”。导出前重新校验 DSL、实体字段和图片资源引用；导出不包含历史、选择状态、画布尺寸、撤销栈或编辑器标记。
- 发布复用现有保存和发布门禁，不因 2.0 UI 跳过任何校验。

## 组件边界

- `DesignStudioView.vue`：页面级编排，将已有 store、顶栏、资源区、画布、检查器、AI 和发布流程组合起来；不承载复杂交互状态。
- `DesignCanvas.vue`：页面 artboard、设备宽度、缩放/平移和 DnD 交互；通过 props 接收有效 DSL/选择状态，通过 emit 回报选择与编辑意图。
- `CanvasPageRenderer`（可放入 PreviewPanel 或专用小组件）：将 `renderPage` 的同一页面渲染器以编辑态参数显示，不维护第二种页面解释器。
- `LayersPanel.vue`：将 UI-DSL 树展示成可访问的图层树，并发出选择/排序意图。
- `ComponentPalette.vue`：按角色任务分组的组件资源库，发出插入意图。
- `DesignInspector.vue`：针对页面/选择节点展示属性编辑器；控件元数据与 DSL schema 有单一映射。
- `useDesignHistory.ts`：管理已验证 DSL 历史、连续输入合并、undo/redo 和历史状态。
- `useCanvasViewport.ts`：管理设备宽度、缩放和平移，不影响 DSL。
- `design-commands.ts`：纯函数命令和 component capability map；检查可拖放关系并创建不可变候选 DSL。
- `packages/page-generator/render-page.ts`：添加可选编辑态 hook/安全节点标记，默认发布/预览行为完全不变。

## 校验与异常

- DSL 校验失败：保留上一个可见且有效的画布，检查器定位错误组件及属性；修正前保存/发布/导出有效 DSL 的动作被阻止。
- 拖放目标不合法：保留选择和页面，显示具体原因，如“按钮不能包含其他组件”。
- 节点删除如果破坏 field、section、navigation、CTA 或 slot 引用，则显示关联项并要求先处理引用或确认级联策略；禁止产生半更新状态。
- 历史恢复同样经过校验；遇到 schema 迁移失败则停止恢复并保留当前状态。
- 图片加载失败、空页面、不可见条件节点和不同设备宽度都有可理解的空/错误状态；运行时异常不能污染导出的 DSL。

## 分阶段交付

1. **画布真实化与直接选择**（已完成首版）：共享安全 renderer 支持可选编辑态节点 ID 与选择回调；中间画布展示真实页面，点击后检查器同步选中；编辑态点击不会触发页面业务事件。
2. **可视化资源区和顶部画布工具栏**（已完成首版）：加入页面画板、桌面/平板/手机宽度、适配/缩放、滚动/平移；空白页面默认显示组件，已有页面默认显示中文图层。
3. **Figma 式设计对象与画布变换**：加入可生成代码的 Frame、Text、Shape 图层；实现指针拖动、8 点缩放、旋转、吸附/对齐；每次变换写回有界 DSL 并通过预览与代码生成。
4. **Figma 式检查器和工具架**：Pages/Layers 左侧结构、底部浮动工具栏、右侧 Position/Layout/Appearance/Typography/Fill；为语义组件和设计图层提供各自的安全属性。
5. **历史与快捷键**：命令边界、合并文本历史、undo/redo、选择/删除/复制/粘贴/多选和对齐操作的可访问快捷键。
6. **导出与质量门禁**：独立 DSL 导出面板、复制/下载、引用校验、修改后保存提示；端到端测试和桌面/手机浏览器视觉验收。

## 完成标准

- 新用户不打开 DSL 源码也能添加区块、在画布选择对象、修改内容并通过图层识别层级。
- 画布渲染和正式预览/发布共享 renderer；画布选择不触发页面业务事件。
- 每个拖放和检查器操作都得到一个有效 DSL 或明确诊断；没有无法导出的视觉状态。
- 参考图中的基本 Figma 操作会实际改变画布对象，并自动落到 DSL；刷新、撤销、重做和导出后结果一致。
- 设计对象的几何、Typography 与 Fill 在 Studio 预览、生成页面和导出 Vue 中保持一致。
- 至少三档 viewport 预览同一页面，缩放不改变 DSL。
- undo/redo 能恢复并重放被支持的所有设计命令。
- 导出的 JSON 可通过 UI-DSL 和引用校验，且不含编辑器状态。
- 现有 T2UI、空白画布、AI 修改、图片、保存、发布和 CLI 导出流程继续工作。

## 方案取舍

**推荐：** 在现有 DSL 与安全 renderer 上构建可视化层，增量扩展 schema 能表达的布局属性。这样维持已有生成与发布链路，并满足设计人员的画布工作方式。

不选“完全自由坐标画布”：它会要求绝对定位、任意 CSS 和新的响应式/代码生成语义，当前 DSL 无法忠实导出。不选“完全替换为 Figma 文档模型”：会复制第二份页面模型，并让现有 UI-DSL 成为不可靠的导出副本。
